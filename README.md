# First Bank Uganda Banking Application

## Project Description

First Bank Uganda Banking Application is a Java desktop banking system developed using Java Swing.
The application allows users to create different types of bank accounts through a graphical user interface.

The project demonstrates Object Oriented Programming (OOP), GUI development, validation,
and file handling in Java.

---

## Features

- Create Savings Account
- Create Current Account
- Create Fixed Deposit Account
- Create Student Account
- Create Joint Account

### Customer Validation

The system validates:

- First Name and Last Name
- National Identification Number (NIN)
- Email address
- Phone number
- PIN number
- Date of Birth
- Minimum opening deposit

---

## Technologies Used

- Java
- Java Swing
- NetBeans IDE
- Object Oriented Programming
- File Handling
