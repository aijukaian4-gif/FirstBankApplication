

# First Bank Uganda - Banking Application

## Description
First Bank Uganda is a Java desktop banking application developed using Java Swing.
It allows users to create different bank accounts, validate customer information,
and save account details using file storage.

## Features
- Create Savings Account
- Create Current Account
- Create Student Account
- Create Joint Account
- Create Fixed Deposit Account
- Customer validation
- NIN validation
- Email validation
- Phone number validation
- Deposit validation
- Account summary generation
- File data storage

## Technologies Used
- Java
- Java Swing GUI
- Object Oriented Programming (OOP)
- NetBeans IDE

## Project Structure

src/
- gui → User interface
- model → Account classes and file management

## How to Run
1. Open the project in NetBeans
2. Build the project
3. Run BankForm.java
